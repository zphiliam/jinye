# 烬野 · Ember Wilds

```bash
git clone https://github.com/zphiliam/jinye.git
cd jinye
npm install
npm run dev
```

浏览器打开 http://127.0.0.1:5180/ 。

一款在浏览器里运行的 2.5D 荒野求生游戏。玩法上受“饥荒”类生存游戏启发，但世界观、角色、生物、界面和声音都是原创的。

**美术**：主角「行者」、树木、植物、岩石、生物、建筑和物品图标是原创的水墨木刻风手绘素材（透明 PNG，放在 `public/art/`），启动时与程序化素材一起打包进 4096² 图集；火焰、光照、地形、粒子、HUD 仍由代码实时生成。资源包加载失败时，游戏会自动退回到全程序化素材。**声音**全部用 Web Audio 程序化合成。

![菜单](screenshots/01-menu.png)

## 运行

需要 Node.js 18 或更高版本，以及支持 WebGL2 的现代浏览器（Chrome、Edge、Firefox、Safari 17+）。

```bash
npm install
npm run dev        # 打开 http://127.0.0.1:5180/
npm run build      # 先做类型检查（tsc），再用 vite build 输出到 dist/
npm run preview    # 预览构建产物：http://127.0.0.1:4180/
```

### URL 参数

| 参数 | 作用 |
| --- | --- |
| `?autostart=1` | 跳过主菜单，直接开局 |
| `?easy=1` | 宽容模式：白天更长、饥饿下降更慢、噬影和蜘蛛伤害更低、蜘蛛追得更慢。菜单里也能切换 |
| `?seed=12345` | 用指定种子生成地图，相同种子得到同一张地图 |
| `?art=proc` | 不加载手绘资源包，改用旧版全程序化素材（对比或排查用） |

参数可以组合使用，例如 `http://127.0.0.1:5180/?seed=7&easy=1&autostart=1`。

## 操作

| 按键 | 作用 |
| --- | --- |
| **W A S D** / 方向键 | 移动 |
| **鼠标左键** | 点地面走过去；点物体执行对应动作（采集、砍、凿、攻击、拾取、添柴）。按住可以连续砍、凿或攻击 |
| **鼠标右键** | 取消当前目标；放置建筑时取消放置 |
| **空格** | 自动采集、拾取最近的东西（按住可以持续） |
| **E** | 与最近的可交互物互动 |
| **F** | 攻击最近的敌人 |
| **Tab** / **C** | 打开或关闭制作面板 |
| **1 – 9, 0, -, =** | 使用或装备快捷栏 1–12 格 |
| 物品格 左键 / 右键 | 左键：使用、食用、装备。右键：在火边烤制、往火里添柴，或丢弃。Shift+左键：丢弃 |
| 装备格 点击 | 卸下装备 |
| **Q / R** | 镜头左转或右转 45° |
| **鼠标滚轮** | 缩放镜头 |
| **M** | 地图 |
| **H** | 操作说明 |
| **N** | 静音 / 取消静音 |
| **Esc** / **P** | 暂停 |

## 玩法

- **三项生存数值**：生命（命）、饥饿（食）、理智（神），显示为 HUD 右上角的圆形表盘。饥饿归零后会掉血；理智过低时画面会扭曲、色散、闪烁，还会听到低语。
- **昼夜循环**：白昼 → 黄昏 → 长夜，右上角的日晷时钟显示当前时段，切换时有横幅提示和音效提示。**长夜几乎一片漆黑**，只有营火、火把、提灯附近能看见。在黑暗里待太久，“噬影”会扑上来伤人（这是本作原创的黑暗威胁）。
- **程序生成地图**：每张地图包含森林、空地、乱石、沼泽四种地形，还有土路、岛屿边缘的悬崖，以及镜头跟随和缩放。
- **采集**：草丛（干草）、树枝丛（枝条）、燧石、浆果丛（会重新长出来）、花朵、芦苇、蘑菇。树要用**斧头**砍，倒下后留下树桩；燧岩要用**镐**凿。工具有耐久度。
- **制作**（Tab）：
  - 一阶：燧石斧、鹤嘴镐、草绳、火把、营火、草编背囊、长矛、研机台
  - 二阶：要先建造研机台，并站在它附近才能研制。研制成功一次之后，这个配方就永久学会了。二阶配方有石砌火坑、提灯、花冠、止血膏、蓑衣甲、木片甲、蛛牙长矛
- **烹饪**：在火边对食物点右键就能烤。熟食回复的数值更多，有的还能回复理智。
- **蜘蛛**：从蛛巢中爬出来，会睡觉、游荡、追击。扑咬之前有明显的**蓄力前摇**，可以躲开。击杀后掉落蛛丝、肉和腺体。蛛巢可以摧毁，之后还会重新生出蜘蛛。
- **其他**：乌鸦会落地啄食，人走近就会飞走。地上有物品掉落和拾取，物品栏有背包扩展格。界面里有情境提示，死亡后会显示死因和这一局的统计，并提供「再来一次」。

## 画面技术

- Three.js（WebGL2）2.5D：倾斜的透视镜头俯瞰 3D 地形，物体是面向镜头的实例化广告牌，支持风中摇曳、被击中时的抖动和闪白，挡住主角的树会自动渐隐。
- 地形着色器混合四种生物群系的程序纹理，再叠加土路、湿地和崖边。
- 动态日月光照、黄昏色调，营火和火把是闪烁的暖色点光源（最多 8 个），精灵有屏幕空间的迎光轮廓光，地面有接触阴影。
- 后期处理：HDR、Bloom、ACES 色调映射、调色、黄昏光柱、纸纹颗粒、暗角，以及黑暗中从屏幕边缘蔓延的墨色触须。
- 粒子：余烬、烟、火星、落叶、尘埃、萤火虫，低理智时还有墨影。
- 在黑暗里待得太久，除了暗处的眼睛，「噬影」会显出身形逼近，出手时扑到身前。
- HUD 是手绘风格的 SVG：圆形表盘、纸张纹理（feTurbulence）、印章式标题。

## 已知限制

- 没有存档，刷新页面就是新的一局。
- 季节、多人、怪物种类、建筑和科技树都是精简版本，只有蜘蛛这一种敌对生物。
- 需要 WebGL2 和较好的显卡。在纯软件渲染（如无头浏览器的 SwiftShader）下能运行，但帧率很低。
- 第一次打开时需要加载约 4 MB 手绘素材并打包图集，通常 2–5 秒，期间显示加载画面。
- 主角每个动作只有一张关键姿势（行走是两张交替加起伏），手持斧头、长矛时站立姿势不显示手中物品，护甲、背包、花冠也不会画在身上。
- 浏览器要求先有用户操作才能播放声音，所以第一次点击或按键之后才会有声音。
- 只适配键鼠，没有触屏操作。

## 目录结构

```
src/
  main.ts          入口：加载画面、主菜单、主循环
  art/             图集打包（atlas.ts）、手绘资源包加载（pack.ts）、主角立绘（hero.ts），
                   以及程序化素材（墨线笔触、火焰、生物、植物、物品、建筑），作为备用和补充
public/art/        手绘素材（透明 PNG）与 manifest.json（图集键 → 源图、世界尺寸、枢轴、镜像）
art-preview/       美术源文件与处理工具：raw/ 原画、tools/extract.py 抠图、tools/build_game_art.py 生成 public/art/
  render/          广告牌精灵、阴影、粒子、昼夜光照、后期处理
  world/           地图生成、地形网格与着色器
  game/            游戏逻辑（Game）、物品与配方、物品栏、实体、输入
  audio/           Web Audio 程序化音效与环境声
  ui/              HUD、SVG 装饰与样式
screenshots/       游戏截图
```
